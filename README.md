## ✨ Features

- 🎴 **Classic Blackjack Rules** - Standard casino blackjack gameplay
- 🌙 **Premium Dark Theme** - Sleek design with glassmorphism effects
- ✨ **Smooth Animations** - Card dealing and status transitions
- 📊 **Stats Tracking** - Wins, losses, and ties counter
- 📺 **Info Screen Optimized** - Designed for large display visibility
- 📱 **Responsive Design** - Works on any screen size

## 🎮 How to Play

1. Click **DEAL** to start a new game
2. Try to get as close to 21 as possible without going over
3. Click **HIT** to receive another card
4. Click **STAND** to keep your current hand
5. Beat the dealer to win!

## 🚀 Getting Started

Simply open `index.html` in any modern web browser:

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/blackjack-info-screen.git

# Navigate to the directory
cd blackjack-info-screen

# Open in browser (or double-click index.html)
start index.html  # Windows
open index.html   # macOS
xdg-open index.html  # Linux
```

## 📺 Info Screen Usage

This game is optimized for display on info screens with:

- Large, readable text and cards
- High contrast colors for visibility
- Automatic scaling for different resolutions
- No external dependencies (works offline)

## 🛠️ Technical Details

- **Pure HTML/CSS/JavaScript** - No frameworks or build tools required
- **No Dependencies** - Only uses Google Fonts (Outfit) for typography
- **Offline Capable** - Works without internet after first load
- **Cross-Browser Compatible** - Works on all modern browsers
